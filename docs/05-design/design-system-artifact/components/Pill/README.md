# Pill

A small rounded label for status and metadata, with Tag as its uppercase sibling for LAB and PRO.

| Variant | Use |
|---|---|
| neutral | Plan names, counts, metadata |
| ok / warn / bad | Status with a dot and a word: Running, Close, Fails to start |
| example | Dashed outline: "sample data", "example name" |
| tag | 10px uppercase: LAB (neutral), PRO (inverted ink) |

Pills are not buttons. Filter chips that toggle use the same shape with `aria-pressed`. State is always a word, never colour alone.
