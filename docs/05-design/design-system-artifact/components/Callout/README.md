# Callout

An inline message that explains a situation and offers the next step.

Variants: neutral (`surface-2` with a `line` border), warn (`warn-soft`, `warn` text), bad (`bad-soft`, `bad` text). Content: a short bold lead, one or two sentences, and at most one action. Radius `radius-xl`, padding 12px 14px.

Use for: things the user should know before acting (why other accounts close during sign-in), problems with a fix (a failing MCP server). Don't use for confirmations that need no action; use a toast.
