# Prototype

`facet.html` is a single-file interactive prototype with sample data. Open it in any browser. Published copy: https://claude.ai/artifact/C5rDdF5JtC5tebDtZ99Dpc

| Version | Date | What changed |
|---|---|---|
| v1–v2 (`history/switchyard-v2.html`) | 2026-10-25 | First concept as "Switchyard": profiles, link router, Observatory, Bridge, Control Center |
| v3 | 2026-10-25 | Rebuilt after research as Facet: account rail and window tint, Today, guided sign-in, Costs with Pro gating, Ecosystem safety preview, Bridge as lab, new Blueprint |
| v4 | 2026-10-25 | Timeline down to the second (zoom, pan, minimap, inspector to the millisecond, keyboard stepping, leaderboards, replay); contrast fixes from the design system |

It is a design artefact, not the app. The app in `app/` will use `docs/05-design/tokens.css` and React components that follow `docs/05-design/DESIGN-SYSTEM.md`.
